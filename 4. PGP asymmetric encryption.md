# Asymmetric encryption with OpenPGP
This short guide explains how to send a file securely using OpenPGP. The sender encrypts with the receiver’s public key, and only the receiver can decrypt it with his private key.

Prerequisites: both parties need Kleopatra (part of Gpg4win on Windows; GPG Suite on macOS).

## Receiver:
1. Install Kleopatra and open it.
2. Create a new fresh key pair: File > New Key Pair > Create a personal OpenPGP key pair.
3. Enter name and email, then set a strong passphrase. It protects the private key and cannot be recovered if lost. 
4. Export the pubkey: right-click the key > Export. This saves a .asc file.
5. Send the .asc file to the sender (any channel).
6. Back up the private key and store it somewhere safe. Without it, files can never be decrypted.

## Sender:
1. Import the receiver’s pubkey: File > Import and select the .asc file.
2. Verify the fingerprint
   * Right-click the imported key > Details and read the fingerprint (i.e. the hash of imported pubkey)
   * Compare it with the receiver over a separate channel (e.g. phone call) 
   * Check the fingerprint with the receiver over a separate channel (e.g. over the phone). Compare every character. If anything differs, do not use the key and ask the receiver to resend it.
3. Encrypt the file you want to send
   * Click Sign/Encrypt and select the file (right-click it > More GpgEX options > Encrypt)
   * Tick "encrypt for others" and select the receiver’s key. (Required)
   * Tick "sign" as if you want to prove the file came from you. (Optional)
   * Tick "encrypt for me" if you want to be able to open your own copy later. (Optional)
   * Click encrypt. This creates file.gpg
   * Send the .gpg file over any channel. If you signed it, also send your pubkey (exported as .asc) so the receiver can verify the signature.
   
## Receivers:
1. If the file was signed, import the sender’s pubkey beforehand and check that Kleopatra reports a valid signature.
2. Right-click the .gpg file > More GpgEX options > Decrypt and verify.
3. Enter the private key passphrase.
4. The output is the original file.
